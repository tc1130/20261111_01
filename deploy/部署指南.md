# 服务器部署与更新指南

## 目录结构（已准备就绪）

```
项目根目录
├── app.py              # 后端代码（已改为生产安全模式，debug 默认关闭）
├── requirements.txt    # 依赖清单
├── .gitignore          # 忽略 uploads/ 和 homework.db（保护数据不被覆盖）
├── templates/          # 前端页面
└── deploy/
    ├── homework.service  # systemd 服务配置（负责常驻后台 + 开关）
    └── nginx.conf        # Nginx 反向代理配置
```

---

## 一、首次部署（只需做一次）

### 1. 服务器安装环境（Ubuntu 22.04）

```bash
sudo apt update
sudo apt install -y python3 python3-venv nginx git
```

### 2. 上传代码到服务器

**方式 A：用 Git（推荐，方便后续更新）**

先把本地代码推送到 GitHub/Gitee 私有仓库，然后在服务器上：

```bash
mkdir -p ~/homework && cd ~/homework
git clone 你的仓库地址 .
```

**方式 B：直接上传**

用 WinSCP 等工具，把项目所有文件上传到服务器的 `~/homework/` 目录。

### 3. 创建虚拟环境并安装依赖

```bash
cd ~/homework
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install gunicorn
```

### 4. 配置 systemd 服务

先改 `deploy/homework.service` 里的两处 `your_username`，改成你服务器的实际用户名。

```bash
# 复制服务文件到系统目录
sudo cp ~/homework/deploy/homework.service /etc/systemd/system/homework.service

# 启动并设置开机自启
sudo systemctl daemon-reload
sudo systemctl enable --now homework
```

### 5. 配置 Nginx

先改 `deploy/nginx.conf` 里的 `your_domain_or_ip`，改成你的域名或服务器公网 IP。

```bash
sudo cp ~/homework/deploy/nginx.conf /etc/nginx/sites-available/homework
sudo ln -s /etc/nginx/sites-available/homework /etc/nginx/sites-enabled/
sudo nginx -t          # 测试配置是否正确
sudo systemctl reload nginx
```

### 6. 完成

浏览器访问 `http://你的服务器IP` 即可使用。

## 二、随时开关网站（重点）

网站部署后由 systemd 管理，你想关就关，想开就开，电脑不用管。

```bash
sudo systemctl stop homework      # 关闭网站（停止服务）
sudo systemctl start homework     # 打开网站（启动服务）
sudo systemctl restart homework   # 重启（改完代码后用它生效）
sudo systemctl status homework    # 查看运行状态
```

说明：
- **开机自启**：`enable --now` 已经设置好，服务器重启后网站会自动运行。
- **你的电脑关不关都没关系**：网站跑在服务器上，和你的电脑无关。

## 三、后续更新网站

核心原则：**只更新代码，不动数据**。

你的数据 = `uploads/`（作业文件）+ `homework.db`（数据库）
你的代码 = `app.py` + `templates/` 等

因为 `.gitignore` 已经排除了 `uploads/` 和 `homework.db`，所以用 Git 拉取更新时不会碰到数据。

```bash
cd ~/homework

# 1. 拉取最新代码（本地改完 push 到 Git 后）
git pull

# 2. 如果依赖有变化，更新依赖
source venv/bin/activate
pip install -r requirements.txt

# 3. 重启服务让新代码生效
sudo systemctl restart homework

# 4. 查看是否正常
sudo systemctl status homework
```

## 四、重要提醒

1. **备份数据**（建议定期做）：

```bash
cd ~/homework
tar -czf backup_$(date +%F).tar.gz uploads homework.db
```

2. **密码是明文存储的**：这是按需求（学委要能查到学生密码）特意设计的。正式上线前建议改为哈希存储，并提供"重置密码"功能。

3. **改数据库结构需谨慎**：SQLite 数据库如果以后改了模型字段（加字段、改表名），`git pull` 不会自动更新旧数据库，需要手动迁移。

4. **文件大小限制**：`app.py` 里 `MAX_CONTENT_LENGTH` 和 `nginx.conf` 里 `client_max_body_size` 都设为 100MB，两者要保持一致。

## 五、常用命令速查

| 操作 | 命令 |
|------|------|
| 启动网站 | `sudo systemctl start homework` |
| 关闭网站 | `sudo systemctl stop homework` |
| 重启网站 | `sudo systemctl restart homework` |
| 查看状态 | `sudo systemctl status homework` |
| 查看实时日志 | `sudo journalctl -u homework -f` |
| 更新代码 | `git pull` + `sudo systemctl restart homework` |
| 备份数据 | `tar -czf backup_$(date +%F).tar.gz uploads homework.db` |
